\section{Difference In Differences and Panel Data}

% ---------------------------------------------------------------
\begin{frame}{Motivation}
\begin{itemize}
  \item Ideally, we want to run an experiment to estimate causal effects. Why?
  \item Often we can't randomly assign people to treatment and control groups.
  \item We can try to mimic an experiment using observational data. 
  \item But we're worried about unsoverable characteristics -- called confounding variables. 
  \item So how should we deal with confounding variables with observational data? 
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Panel Data}
\begin{itemize}
  \item We observe observations for
  each unit $i$ (say a person or geography) across multiple periods $t$
  \item Why is this useful? \pause It allows us to look at differences in outcomes
  between treated/untreated units before the treatment occurred
  \item If treated/control outcomes are different before the treatment, this
  must be the result of confounding factors.
  \item So we can potentially use pre-treatment differences to learn about the
  confounds and adjust for them
  \item Example: difference-in-differences,
  which is the most common panel data method used in applied
  microeconomic research
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Example of Diff-in-Diff Setup (Purely Hypothetical)}
\begin{itemize}
  \item Suppose we want to understand the effect of marriage on income (of women) 
  \item Why might marriage affect income? 
  \item We can't randomly assign marriage! So we have to use observational data
  \item Suppose we only observe post-marriage data on income. What happens if we take the difference of avg. income between married and unmarried folks?
  \item Omitted variables! Endogeneity! Selection bias!
  \item In particular, women who choose to marry may have had lower income potential even if they had not married.
  \item But with panel data, we can actually see what these income differences were before marriage!
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{}
\begin{itemize}
  \item Draw figure \pause
  \item Before marriage, say, unmarried women had an average income 20K higher in every period 
  \item Can we assume uncofundedness now? \pause No! 
  \item A better assumption: the gap would have remained 20K over time, if the married women had not married
  \item This is the idea behind difference-in-differences (DiD)
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{}
\begin{itemize}
  \item After the marriage, married women have an average income 30K lower 
  \item Under the assumption that the difference should have been 20K, we can attribute the extra 10K difference to marriage
  \item Thus the treatment effect is the post-treatment difference minus the pre-treatment difference
\end{itemize}
\end{frame}
% ---------------------------------------------------------------


% ---------------------------------------------------------------
\begin{frame}{Formalizing the Assumptions of DiD}
\begin{itemize}
  \item Assume there are 2 periods, $t = 1,2$. Treated units ($D_i = 1$) are
  treated in period 2; control units never-treated.
  \item Let $Y_{it}$ be the observed outcome for unit $i$ in period $t$.
  Assume $Y_{it} = D_i\, Y_{it}(1) + (1 - D_i)\, Y_{it}(0)$
  \item Assumption 1: \textbf{No anticipation.} $Y_{i1}(1) = Y_{i1}(0)$.
  \begin{itemize} 
    \item The treatment in period 2 does not affect outcomes in period 1.
  \end{itemize}
  \item Assumption 2: \textbf{Parallel trends.} \\
  \begin{equation*}
    E[Y_{i2}(0) - Y_{i1}(0) | D_i = 1] = E[Y_{i2}(0) - Y_{i1}(0) | D_i = 0]
  \end{equation*}
  or equivalently,
  \begin{equation*}
    E[Y_{i2}(0) | D_i = 1] - E[Y_{i1}(0) | D_i = 0] = E[Y_{i1}(0) | D_i = 1] - E[Y_{i1}(0) | D_i = 0]
  \end{equation*}
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Identification}
\begin{itemize}
  \item Under the assumptions above, we have:
  \begin{align*}
    E[Y_{i2} - Y_{i1} | D_i = 1] - E[Y_{i2} - Y_{i1} | D_i = 0] 
    \\ = E[Y_{i2}(1) - Y_{i1}(1) | D_i = 1] - E[Y_{i2}(0) - Y_{i1}(0) | D_i = 0] \\
    = E[Y_{i2}(1) - Y_{i0}(0) | D_i = 1] - E[Y_{i2}(0) - Y_{i1}(0) | D_i = 0] \\
    = E[Y_{i2}(1) - Y_{i2}(0) | D_i = 1]  + E[Y_{i2}(0) - Y_{i1}(0) | D_i = 1] - E[Y_{i2}(0) - Y_{i1}(0) | D_i = 0] \\
    = E[Y_{i2}(1) - Y_{i2}(0) | D_i = 1]
  \end{align*}
\item Thus, the difference in differences identifies the average treatment effect on the treated (ATT):
  \begin{equation*}
    \beta_{ATT} = E[Y_{i2}(1) - Y_{i2}(0) | D_i = 1]
  \end{equation*}
\item The ATT is the average effect in period 2 for those units that were treated.
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Estimating the ATT}
\begin{itemize}
  \item So under the DiD assumptions, we show that the ATT is identified as follows:
  \begin{equation*}
    \beta_{ATT} = E[Y_{i2} - Y_{i1} | D_i = 1] - E[Y_{i2} - Y_{i1} | D_i = 0]
  \end{equation*}
  \item How can we estimate this? \pause Plug in sample analogues (means, in this case):
  \begin{equation*}
    \hat{\beta}_{ATT} = (\bar{Y}_{12} - \bar{Y}_{11}) - (\bar{Y}_{02} - \bar{Y}_{01})
  \end{equation*}
    where $\bar{Y}_{dt}$ is the sample mean for group with units $D_i=d$ in period $t$.
\end{itemize}
\end{frame}
% ---------------------------------------------------------------


% ---------------------------------------------------------------
\begin{frame}{Diff-in-Diff Regression}
\begin{itemize}
  \item Consider the regression:
  \begin{equation*}
    Y_{it} = \beta_0 + \beta_1 Post_t + \beta_2 D_i + \beta_{3} (Post_t \times D_i) + \epsilon_{it}
  \end{equation*}
\item $\beta_3$ is equal to $\beta_{ATT}$ under the DiD assumptions. How?
\item Analogously, $\hat{\beta_3} = \hat{\tau}_{ATT}$
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Parallel Trends}
\begin{itemize}
  \item DiD relies on the parallel trends assumption, which allows for selection
  bias but requires it to be stable over time. This rules out time-varying
  confounding factors.
  \item Often we will be worried about time-varying confounds — e.g.,
  promotions at work for single versus married women in general
  \item Testing for pre-treatment differences (``pre-trends'') can help increase
our confidence in the research design. But they’re not perfect. Why?
\begin{itemize}
  \item Just because trends were parallel beforehand doesn’t mean that they
  would continue to be afterwards
  \item Often our estimates of pre-trends are noisy so we’re not sure whether
  they’re actually zero or not.
\end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{Standard Errors in Panel Data}
\begin{itemize}
  \item In standard OLS, we assume that $Y_i, X_i$ are i.i.d. across $i$.
  $Y_i = X_i ' \beta + e_i$.  
  \item With panel data, we have $Y_{it} = X_{it} ' \beta + e_{it}$.
 \item Is the independence assumption still valid? No! Why not?
 \begin{itemize}
  \item Now they have to be i.i.d across both $i$ and $t$.
  \item Generally expect $Y_{i1}$ and $Y_{i2}$ to be correlated for the same unit $i$ - serial autocorrelation.
  \item If treatment is assigned at a higher level, e.g., state level, then observations within a state will be correlated. 
\end{itemize}
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Clustered Standard Errors}
\begin{itemize}
  \item Clustering SEs allows for correlations across observations within a cluster.
  \item So each cluster is sampled independently. 
  \item Example: with individual clustering, we allow $Y_{i1}$ and $Y_{i2}$ to be correlated for the same individual $i$.
  \item But independent for different individuals $i \neq j$.
 \item Best practice: always cluster at the level of treatment assignment.
 \item Important: the number of clusters becomes the effective sample size for SEs.
 \begin{itemize}
  \item So they should be large enough (e.g., $> 30$).
  \item Otherwise, unreliable 
\end{itemize}
\end{itemize}
\end{frame}

\section{Instrumental Variables with Panel Data}
% ---------------------------------------------------------------
\begin{frame}{Motivation}
\begin{itemize}
  \item Sometimes we don't have an RCT or even panel data
  \item Need to worry about other confounding unobservable variables
  \item In some of these cases, we may need to use instrumental variables (IV) methods
  \item Basic idea: if the causal relationship between $Y_i$ and $X_i$
  is confounded, find a $Z_i$ which “exogenously” shocks $X_i$
  \item What does that mean? Back to the Mincer equation!
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Mincer Returns to Education}
\begin{itemize}
  \item Let $Y_i$ be earnings, $X_i$ be years of schooling, and $\epsilon_i$ be unobserved ability.
  \item $Y_i = \alpha + \beta X_i + \epsilon_i$
  \item What's the problem with the OLS estimate of $\beta$? \pause
  \item Ability matters! $Cov (X_i, \epsilon_i) \neq 0$
\end{itemize}
\end{frame}
% ---------------------------------------------------------------
% ---------------------------------------------------------------
\begin{frame}{Mincer Returns to Education}
\begin{itemize}
  \item Suppose we observe the outcome of a college lottery that offers scholarship, $Z_i$. 
  \item If $Z_i = 1$, individual $i$ wins the lottery and gets a scholarship.
  \item If it truly is a lottery, then in some sense, $Z_i$ is randomly assigned and $Cov(Z_i, \epsilon_i) = 0$.
  What does that get us? \pause
  \item $ Cov (Z_i, Y_i) = Cov (Z_i, \alpha + \beta X_i + \epsilon_i) = \beta Cov (Z_i, X_i)$
  \item So we can estimate $\beta$ as:
  \begin{equation*}
    \beta = \frac{Cov (Z_i, Y_i)}{Cov (Z_i, X_i)}
  \end{equation*}
as long as $Cov (Z_i, X_i) \neq 0$.
\item So $Z$ is an instrument for $X$.
\end{itemize}
\end{frame}

% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{IV Mechanics}
\begin{itemize}
  \item Consider two equations:
  \begin{align*}
    Y_i &= \kappa + \rho Z_i + \nu_i \\
    X_i &= \mu + \pi Z_i + \eta_i
  \end{align*}
  \item The IV estimand can be written as the ratio of two covariances:
  \begin{equation*}
    \frac{Cov (Z_i, Y_i)}{Cov (Z_i, X_i)} = \frac{Cov (Z_i, Y_i) / Var(Z_i)}{Cov (Z_i, X_i) / Var(Z_i)} = \frac{\rho}{\pi}
  \end{equation*}
  \item We need $Cov (Z_i, \nu_i) = Cov (Z_i, \eta_i) = 0$ for this to be valid.
  \item With binary $Z_i$, this is equivalent to:
  \begin{equation*}
    \frac{E[Y_i | Z_i = 1] - E[Y_i | Z_i = 0]}{E[X_i | Z_i = 1] - E[X_i | Z_i = 0]} = \frac{\rho}{\pi}
  \end{equation*}
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{Heterogeneous Effects}
\begin{itemize}
  \item In previous version, we assumed constant treatment effects.
  \item $\beta$ was the same for everyone.
  \item But effects can be heterogenous across individuals $\implies \beta_i$.
  \item In particular, when compliance is not perfect, we have:
  \begin{equation*}
    Y_i = \alpha + \beta_i X_i + \epsilon_i
  \end{equation*}
  \item In this case, IV estimates a Local Average Treatment Effect (LATE).
  \item LATE is the average effect for compliers -- those whose $X_i$ is affected by $Z_i$.
\end{itemize}
\end{frame}
% ---------------------------------------------------------------


% ---------------------------------------------------------------
\begin{frame}{Validity of an Instrument}
\begin{itemize}
  \item Key validity condition: $Cov (Z_i, \epsilon_i) = 0$.
  \item Requires two distinct assumptions:
  \begin{itemize}
    \item As good as random assignment: the instrument must not depend on potential outcomes $Y_i(0), Y_i(1)$ systematically. 
    \item Exclusion restriction: the instrument affects $Y_i$ only through its effect on the $X_i$.
  \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{Estimating IV}
\begin{itemize}
  \item With binary $Z_i$, we can write the IV estimand as a function of population means:
  \begin{equation*}
    \beta = \frac{E[Y_i | Z_i = 1] - E[Y_i | Z_i = 0]}{E[X_i | Z_i = 1] - E[X_i | Z_i = 0]}
  \end{equation*}
  under the conditions that $Cov (Z_i, \epsilon_i) = 0$ and $Cov (Z_i, X_i) \neq 0$.

  \item We can estimate this using sample analogues (means):
  \begin{equation*}
    \hat{\beta} = \frac{\bar{Y}_{Z=1} - \bar{Y}_{Z=0}}{\bar{X}_{Z=1} - \bar{X}_{Z=0}}
  \end{equation*}
  \item More generally, we can use the ratio of the reduced form and first stage coefficients from two OLS regressions:
  \begin{itemize}
    \item First stage: $X_i = \hat{\mu} + \hat{\pi} Z_i + \hat{\eta}_i$
    \item Reduced form: $Y_i = \hat{\kappa} + \hat{\rho} Z_i + \hat{\nu}_i$
    \item Then $\hat{\beta}_{IV} = \frac{\hat{\rho}}{\hat{\pi}}$
  \end{itemize}
\end{itemize}
\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Quasi-Experimental Evidence}
\begin{itemize}
  \item Sometimes, the instrument can actually be randomly assigned -- e.g., lottery
  \item In other settings, researchers use an instrument that is not explicitly
  random but may be the result of idiosyncratic factors that are
  potentially “as-good-as-random”
  \item This expands the set of cases where we can use IV, but it means the
  required assumptions deserve extra scrutiny
  \begin{itemize}
    \item As-good-as-random means $Z_i$
    is uncorrelated with background factors
    relevant for the outcome
    \item Remember we still need to gauge exclusion: $Z_i $doesn’t affect outcomes
    except through the specified treatment
  \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{Treatment Effect for Whom?}

\begin{frame}{Weak Instruments}
\begin{itemize}
\item Remember, $\hat{\beta}_{IV} = \frac{\hat{\rho}}{\hat{\pi}}$
\item If $ \hat{\pi} \lim 0$, then $\hat{\beta}_{IV} \lim \infty$!
\item This is the \textit{weak instruments} problem - $\hat{\beta_{IV}}$ becomes biased towards the OLS
\end{itemize}
\end{frame}
% ---------------------------------------------------------------
% ---------------------------------------------------------------
\begin{frame}{Testing for Weak IV}
\begin{itemize}
\item A typical rule of thumb is to worry about many/weak instruments if
the F-statistic on the instruments in the first stage is less than 10
\item That is, run the first stage regression:
\begin{equation*}
X_i = \mu + \pi Z_i + \eta_i
\end{equation*}
\item Construct the F-statistic for the null hypothesis that $H_0: \pi = 0$
\item With one instrument, this is just the square of the t-statistic on $\hat{\pi}$
\item So $F > 10$ implies $|\text{t-stat}| > \sqrt{10} \approx 3.16$
\end{itemize}
\end{frame}
% ---------------------------------------------------------------

% ---------------------------------------------------------------
\begin{frame}{How to solve the weak IV problem}
\begin{itemize}
\item Split the sample and use part of the sample to select strong instruments
\item Get a larger sample 
\item Add control variables that correlate with X but not with $Z$
\item Come up with a new instrument! (it's hard tho) 
\end{itemize}
\end{frame}
